Actividad práctica realizada

Se desarrolló Voltio Lab, una tienda web de componentes electrónicos dirigida
a makers, estudiantes y personas interesadas en el prototipado. La interfaz se
implementó con HTML, JavaScript, Vite y Tailwind CSS, tomando como referencia
un diseño editorial de alto contraste con navegación, catálogo filtrable,
carrito y acceso administrativo.

El backend fue migrado a NestJS sobre Node.js 20 y se conectó con PostgreSQL
14 mediante la variable de entorno DATABASE_URL. La API REST expone el
catálogo público, autenticación administrativa, operaciones protegidas sobre
productos, consulta de órdenes y checkout. La base de datos normaliza usuarios,
productos, órdenes, artículos y pagos, con claves foráneas, restricciones de
categoría y validación de cantidades. Las contraseñas se derivan con scrypt y
las rutas administrativas requieren Bearer token.

El trabajo se organizó mediante Spec Driven Development. La carpeta specs
contiene constitution.md, spec.md, plan.md y tasks.md, donde se establecen el
alcance, las historias de usuario, requisitos funcionales, criterios de
aceptación, arquitectura y trazabilidad. Cada cambio se trabajó en ramas
feature/* y se integró mediante Pull Requests, CODEOWNERS y protección de la
rama main.

La calidad se automatizó con GitHub Actions en Ubuntu y Node.js 20. El pipeline
instala dependencias con npm ci, ejecuta las pruebas del backend NestJS, compila
la API, ejecuta las pruebas y el lint del frontend y genera el build de Vite.
Este flujo mantiene una validación reproducible antes de aceptar cambios en
main y deja evidencia de la colaboración, la revisión y la entrega continua.
